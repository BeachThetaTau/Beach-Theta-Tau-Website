# Running deliberations

1. Import and verify all candidate records.
2. Open `/admin/deliberations` with an admin account.
3. Select a candidate card. Selection updates `selectedDelib`, which updates member ballots in real time.
4. Monitor vote totals while the candidate modal is open.
5. Toggle bid status only after the chapter reaches a decision.
6. Download the CSV results and store them according to chapter policy.
7. Clear or archive sensitive deliberation data after the process concludes.
